Receiver log & setup notes

Only one SDRone is used: it samples the full 10 MHz window, and each selected signal is digitally frequency-shifted, filtered and decimated from that same capture. All users share this one receiver; no second SDR is needed. If several are connected, choose one at startup. Users watching the same signal with matching search settings share one native server decoder. Existing users retain capture center/span/gain; new viewers join that configuration. Only recovered MPEG-TS, compact spectrum data and status cross the network. Video/audio decoding stays in your browser. Auto mode tries DVB-S2 PLS/MODCOD detection, then DVB-S FEC candidates; automatic symbol-rate search tries up to three nearby common rates using the measured RRC spectrum width. These are estimates until decoder lock and CRC-valid PAT/PMT tables confirm a transport stream. Custom rates, roll-off and difficult signals may need manual settings. Search progress is shown; no successful lock is claimed from a spectrum alone.

QO-100 WB is 10490.5–10499.5 MHz RF (740.5–749.5 MHz IF with a 9750 MHz LNB). Center/tune inputs use IF MHz; labels add LNB LO and correction. Use an external, DC-isolated LNB power inserter, usually 18 V / 22 kHz off for low-band horizontal reception. The SDR bias tee stays off. DVB-S2 uses hard-decision LDPC bit-flipping and BCH; weak-signal performance is limited. DVB-S2X, multistream and GSE are unsupported. Waterfall only releases your decoder subscription. The final viewer leaving stops the channel decoder, and the last receiver user leaving releases the SDR. TS downloads retain the most recent 32 MiB.
