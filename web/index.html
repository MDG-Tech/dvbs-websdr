Receiver log & setup notes

QO-100 WB uses 10490.5–10499.5 MHz RF (740.5–749.5 MHz IF with a 9750 MHz LNB). Use the QO-100 preset for a 10 MHz overview, then click a signal and select its symbol rate. The beacon preset selects DVB-S2, 1500 ksym/s, QPSK 4/5 at 10491.5 MHz. Center and tune controls remain in IF MHz; the heading and waterfall show RF when an LNB LO is entered. LO correction adds to the nominal LO when labeling RF. A universal LNB needs external low-band, horizontal-polarization power (usually 18 V, 22 kHz off), isolated from the SDR input. The SDR bias tee stays off. Full-span FFT and channel extraction run on the host; DVB-S/S2 demodulation and media decoding run in the browser. DVB-S2 uses built-in hard-decision LDPC bit-flipping and BCH; weak-signal performance is limited. DVB-S2X, multistream and generic streams are not supported. TS downloads retain the most recent 32 MiB.
